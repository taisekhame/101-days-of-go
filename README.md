# 101 Days of Go

My daily log of learning Go (Golang). Each folder is one day, with the code I wrote that day.

I planned 100 days, started a day late, and decided to count that missed day as Day 0. So it's 101.

## Run any day

From the root of the repo:

    go run ./day-18-channels

Or go into the folder and run the file directly:

    cd day-18-channels
    go run index.go

Days 5 and 10 are interactive and wait for you to type. Day 15 creates a `sample.txt` the first time it runs. Generics (Day 16) needs Go 1.18 or newer.

## How the repo is organized

- Each day has its own folder named `day-NN-topic`.
- `index.go` is the main example for the day.
- `practice/` holds extra practice files, one numbered subfolder each, each with its own `index.go`.
- `notes.md` is on days where I wrote notes instead of code.
