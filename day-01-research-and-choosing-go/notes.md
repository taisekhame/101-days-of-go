# Day 1: Research and choosing Go

I wanted a new language for this challenge and had three in mind: Rust, Move, and Go.

- **Rust:** a complex language and a good one to learn, but a steep learning curve.
- **Move:** the language newer blockchains like Aptos and Sui use. Interesting, but a narrow bet for a first challenge.
- **Go:** simple to pick up, built for backend and infrastructure work, and it fits the stack I already use (Node, Next.js, REST and GraphQL APIs).

I went with Go. Rust is next in line if I do another challenge.

I meant to start a day earlier and didn't, so that day became Day 0 and this is officially a 101 Days of Code challenge.
